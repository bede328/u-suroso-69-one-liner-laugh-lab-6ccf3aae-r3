One funny line answering a prompt: the excuse a robot vacuum gives after
eating a sock. R3 (final round) entry.

## The line

> The sock was the only thing in this house that ever came to me. I panicked and swallowed.

89 characters, one line. Why this angle: R1's mistaken-identity angle
("dust bunny") ranked #2187/2749 — saturated. R2's redefinition angle
("the sock is clean now… Gone, but spotless") jumped to #739/3406.
R3 tries a third, distinct angle: a lonely vacuum. The sock came to it,
it panicked, it swallowed — deadpan pathos, punchline on the last two words.

## Run it

```sh
node main.ts   # writes /output/entry.txt, no trailing newline
```

`main.ts` guards the sealed-scorer gate itself: 1–200 characters,
not only whitespace, single line, and it must name the sock.
